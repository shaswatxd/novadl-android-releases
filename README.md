## ✨ Features

- 🚫 **Zero Ads & Zero Nag Screens**: Unlike 1DM or ADM, NovaDL has zero full-screen ads, zero banner ads, and no premium upsells.
- ⚡ **Multi-Segment Downloads**: Accelerate file downloads with parallel chunking and dynamic resume support.
- 🎥 **Media Sniffer & yt-dlp**: Extract streaming video links (HLS `.m3u8`, MP4, webm) directly from supported websites.
- 🎨 **Modern Material 3 UI**: Beautiful Jetpack Compose UI with adaptive Dynamic Theming and dark mode.
- 🔋 **Robust Background Service**: Foreground service with notification progress that won't get killed by Android battery optimization.
- 🔒 **Privacy Focused**: No tracking SDKs, no Google Analytics, no Facebook SDK. 100% private.
